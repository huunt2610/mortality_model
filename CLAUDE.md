# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Master's thesis (Luận văn Thạc sĩ, ĐH KHTN – ĐHQG-HCM) forecasting Vietnamese mortality using
stochastic mortality models (Lee-Carter, Renshaw-Haberman, Cairns-Blake-Dowd), with an
actuarial/insurance risk-management application. It is a research pipeline, not a library — no
CLI, no package to install. **Read `README.md` first** — it is the authoritative project doc,
including a full Vietnamese/English/LaTeX notation glossary; don't duplicate it here.

## Language split: Python vs R

- **Python** (`src/`, `notebooks/`): data ingestion, EDA, evaluation, plotting.
- **R** (`R/`): model fitting via `StMoMo`, forecasting, backtesting.
- They interoperate **through the filesystem only** (CSV files in `data/processed/` and
  `models/`), not in-process — there is no reticulate/rpy2 bridge.
- Notebooks should only call functions from `src/`/`R/`, not contain long logic themselves.
- **Notebooks 03–08 are placeholders/stubs** — only 01 (data collection) and 02 (EDA) have
  real content. Don't assume the later ones reflect working analysis.

## Config

`config/params.yaml` is the single source of truth for age ranges, year ranges, and
train/test splits — read from here in both Python (`src/config.py::load_params()`) and R
(`yaml::read_yaml(...)`), never hardcode these elsewhere. Age ranges differ by model: LC/RH
use 0–90, CBD uses only 55–90 (old-age focus). COVID years (2020–2022) are flagged via
`exclude_covid_years`; backtests should be reported both with and without them.

## Data pipeline

- Flow is strict **raw → interim → processed**, code-only, re-runnable from scratch. Raw data
  is immutable — never hand-edit source Excel files.
- `data/raw/` and `data/interim/` are gitignored (only `.gitkeep` tracked). Raw UN WPP Excel
  files must be manually downloaded from https://population.un.org/wpp/ into `data/raw/`
  with exact filenames from `data/external/SOURCES.md` / `src/data/make_dataset.py::WPP_FILES`
  before `python -m src.data.make_dataset` will run — it raises `FileNotFoundError` with
  instructions otherwise.
- `data/processed/` matrices are named `Dxt_{sex}.csv`, `Ext_{sex}.csv`, `mx_{sex}.csv` with
  sex ∈ {male, female, total}, indexed by age (rows) × year (columns), ascending and
  contiguous — validated by `src/data/validate.py::validate_matrices`.
- UN WPP files don't separate deaths from exposure: `Dxt = mx * Ext` is an assumption, and
  `Ext` is approximated from `L(x,n)`, not observed directly.
- Exposure-type convention (common source of fitting mistakes): use `E^c` (central exposure)
  with `m_{x,t}` + log link, or `E^0` (initial exposure) with `q_{x,t}` + logit link. In
  StMoMo this is `type = "central"` vs `"initial"`.
- `models/*.rds`/`*.pkl` and `references/*.pdf` are also gitignored — don't expect them after
  a fresh clone.

## Figures

Every thesis figure is generated by one function in `src/visualization/plots.py`, ending with
a shared `_save(fig, name)` helper that writes **PDF at dpi=300** to `reports/figures/`
(not PNG — this was a deliberate switch).

## Code style

- Python docstrings/comments: full Vietnamese with diacritics.
- R comments: Vietnamese **without** diacritics (ASCII-only, to avoid R console encoding
  issues).
- Variable/function names use English actuarial notation (`Dxt`, `Ext`, `mx`,
  `build_life_table`, `poisson_deviance`) — keep consistent with the README's notation table.
- R model fitting: RH uses `cohortAgeFun = "1"` (β₀=1, per Haberman & Renshaw 2011) and is
  initialized from the LC fit; expect slow convergence (`iterMax = 1e5`), and check
  `RHfit$conv`. Default series is `"total"` unless fitting by sex explicitly.

## Commands

python -m venv .venv && source .venv/bin/activate

# R setup
Rscript R/00_install_packages.R

# Data pipeline
python -m src.data.make_dataset

# Fit models
Rscript R/02_fit_models.R

# Tests
pytest

# Lint
ruff check .        # Python (config: ruff.toml)
