# Quy ước code style

- Docstring/comment Python: tiếng Việt đầy đủ dấu.
- Comment R: tiếng Việt **không dấu** (chỉ ASCII, để tránh lỗi encoding trên console R).
- Tên biến/hàm dùng ký hiệu actuarial tiếng Anh (`Dxt`, `Ext`, `mx`, `build_life_table`,
  `poisson_deviance`) — giữ nhất quán với bảng ký hiệu trong README.
